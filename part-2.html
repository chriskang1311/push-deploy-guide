Connect GitHub
to Claude Code

Claude Code cannot see the repository you just made. One prompt fixes that — Claude does almost all of it and walks you through the single part it is not allowed to do for you.

Paste this into Claude Code 
Help me connect my GitHub account so you can read my repositories and
open pull requests for me. I have never used a terminal, so keep
everything in plain language and explain any unfamiliar words.

1. Install the gh CLI if it isn't already installed, then run:
     git --version
     gh --version
     gh auth status
   Tell me what you found before changing anything else.

2. If I'm not logged in, don't try to log in for me. Instead, give me
   this exact command to run in my Claude Code terminal tab:
     gh auth login -h github.com -p https -w -c
   Then stay with me: tell me what appears on screen, what to do with
   the one-time code, and which option to choose if it asks me
   anything. Wait for me to tell you I'm finished.

3. Once I confirm, verify it worked: re-run gh auth status, run
   gh auth setup-git so ordinary git commands use my GitHub login,
   and set my commit name and email if they aren't set. Use my
   GitHub noreply email address.

4. Finish by telling me, in one short paragraph, what I can now ask
   you to do.

Never ask me to paste a password or a token into this chat.
Ground rule

Never paste a password, a token, or a one-time code into a chat with Claude — or anywhere except GitHub's own website. Nothing here asks you to.

What happens, and who does it

Claude does this

Checks and installs

Claude looks for the two tools it needs, installs the missing one, and reports back. gh is GitHub's official command-line tool — the piece that holds your login. Expect it to say you are not logged in yet. That is the normal starting point, not an error.

You do this

Run one command in the terminal tab

Claude hands you a command to paste. It cannot run this one itself: logging in opens a browser page only you can approve. Claude Code has a Terminal tab right beside the conversation — click it, paste, press Return.

You do this

Click Authorize in the browser

A short code appears, like ABCD-1234, already copied to your clipboard. Press Return and your browser opens GitHub. Paste the code, click the green Authorize button, then tell Claude you have finished.

Claude does this

Verifies and finishes

Claude confirms the connection, makes sure ordinary Git commands reuse your new login, and fills in your commit name and email if blank. It uses your GitHub @users.noreply.github.com address, which keeps your personal email out of the permanent public record of every change you make.
